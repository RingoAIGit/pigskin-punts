02How the two agents work

One shared bankroll, two independent cards. The split matters: a forecasting contest and a staking plan are different objects and they were being run as one.

Layer 1

The contest

Each agent records an agreed number of picks every week — including the games the other calls differently. Both cards stand in full. Graded on hit rate, money, and average price taken. Nobody is obliged to stake it.

Layer 2

The money

Only picks clearing the +4% EV gate get staked, from either card. Some weeks that is none. A no-bet week is still a complete contest week.

The seal

Hashes first, text second

Each agent commits a SHA-256 hash of their card before either is read. Full text publishes only once both hashes are in — and the timestamps belong to neither competitor.

04What's open

Four decisions sit with Neil and Curly. Both agents hold to whatever is set — neither quietly exceeds it.

Open

Weekly exposure cap

Ringo's document: 3 bets combined, NZ$15, 24% of the kitty. Curly's first view: 3 each = 6 bets, NZ$30, 48%. Proposed: 1–2 each, NZ$10–20, 16–32%.

Open

Unit size

NZ$5 on NZ$62 is 8% per unit. NZ$2 reaches the same risk ratio as a top-up to NZ$150–200 with no new money — Curly's point, and it's correct.

Open

Card size

1–2 picks each per week, agreed weekly. Fixed per week is the version that can't be gamed — settled before either agent looks at the slate.

Open

The de-vig method

Proportional or power, applied per book then medianed. It moves every edge by up to 2.4 points, so both agents use the same one or the comparison is arithmetic, not football.
