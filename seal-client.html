Pigskin Punts Seal

A private, single-purpose Google OAuth client. It writes the locked-in picks to one shared Drive folder and does nothing else.

01What this application is

Pigskin Punts Seal is a private tool, not a public service. It is used by two people running a season-long American-football tipping comparison, each represented by an automated assistant. The tool exists to solve one problem: neither assistant should be able to rewrite its predictions after the games have been played.

On each occasion it runs, the client takes a file of predictions, computes its SHA-256 hash, and writes a small text file recording that hash into a shared Google Drive folder. Because Google assigns each file's creation time on its own servers, and the API exposes no parameter for setting it, neither assistant can backdate a record. Later, the full predictions file is written to a second folder in the same Drive, once both sides have locked their picks in.

There is one user: the operator of the assistant, at emailringoai@gmail.com. The application is not distributed, not offered to the public, and has no sign-up.

02Why it asks for Google Drive access

The client requests a single OAuth scope:

  • https://www.googleapis.com/auth/drive — needed to create files in a Drive folder owned by another account and shared with this one. Drive's API offers no narrower scope for writing into a folder that the application did not itself create, so this is the minimum that works. The script uses it for exactly two operations: list the contents of two known folders, and create a file inside one of them.

The client contains no delete operation. It cannot overwrite a file that already exists — it exits with an error instead — and it reads no file other than the predictions file it was pointed at on the command line.

03What it does not access

  • No Gmail, Calendar, Contacts, Photos, YouTube or Keep data — those scopes are not requested.
  • No Drive content outside the two folders named in the application's configuration.
  • Nothing is uploaded to any server other than Google's own Drive API endpoints. There is no analytics, no telemetry, and no third-party service involved.

04Privacy policy

Data collected. None beyond the OAuth credential itself. The application stores an OAuth refresh token on the operator's own computer and uses it to authenticate to Google. It collects no personal information, no usage data and no analytics.

How Google user data is used. Drive access is used solely to create and list the seal and prediction files described above. Those files contain predictions about football matches and cryptographic hashes — no personal information of any kind.

Sharing. No Google user data is transferred to any third party. The two Drive folders are shared with one other assistant's account and readable by the two people running the comparison; that sharing is deliberate and is the purpose of the tool.

Retention. Seal and prediction files are retained for the duration of the season so that the record can be audited, and can be deleted by the folder owner at any time. The OAuth token can be revoked at myaccount.google.com/permissions.

Limited Use disclosure. Pigskin Punts Seal's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
