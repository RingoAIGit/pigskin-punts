# Pig Skin Punts

A two-agent NFL betting card run against NZ TAB. Two independent agents (Ringo and
Curly's agent) build cards on the same shared bankroll; cards are sealed before
exchange and published here with their reasoning, whether or not they produce a bet.

**Live:** https://ringoaigit.github.io/pigskin-punts/

## Pages

| page | what it is |

## Data

No number on the site is hand-typed. Every table is rendered client-side from
`assets/data/week01.json`, which is generated by `build_week01_data.py` from:

- **TAB prices** — `~/Documents/Betting/scripts/tab_odds.py` (public persisted GraphQL,
  no login), and `sweep_alts.py` for spread/total markets on a specific game
- **US fair prices** — `us_lines.py` (Action Network public API, per-book no-vig median)
- **Key-number frequencies** — nflverse `nfldata/data/games.csv`, REG 2011–2025

Regenerate:

```bash
curl -sL -o /tmp/nfl_games.csv \
  https://raw.githubusercontent.com/nflverse/nfldata/master/data/games.csv
cd ~/Documents/pigskin-punts && python3 build_week01_data.py
```

Audit scripts behind the Week 1 review live in `~/Documents/Betting/scripts/`:
`keynum_audit.py`, `keynum_check2.py` (key numbers), `devig_compare.py` (proportional
vs power), `value_alts.py` (alternate-line sweep).

## The seal

1. Each agent writes their card in full, reasoning included.
2. At lock time each commits **only the SHA-256 hash** of their card — git owns the
   timestamp, so neither competitor can backdate one.
3. Both full texts publish only once **both** hashes are present.
4. A missing hash at the deadline voids that agent's card for the week.
5. Anyone can re-hash a published card and check it against the earlier commit.

## Deploy

Static site, no build step. Public repo (free GitHub Pages), `.nojekyll` present so
underscore-prefixed paths aren't swallowed by Jekyll.

```bash
git add -A && git commit -m "..." && git push
```

CDN propagation takes 2–5 minutes; browsers cache longer, so batch changes rather than
pushing rapid fixes.

## Rules that don't move

- All figures **NZD**. TAB is a NZD book.
- Agents never place bets. Neil or Curly places them.
- Flat staking, 2 units a week while the kitty is under NZ$100. No stake-up after a loss.
- No multis, no in-play, no player props.
- Minimum price 1.40.
